### Как установить MikaruStart как главную страницу:

#### Google Chrome / Яндекс.Браузер / Opera
1. Скачайте файлы проекта и сохраните папку на компьютере (например, в `C:/MikaruStart/`).
2. Откройте файл `index.html` в браузере. Спишите/скопируйте его адрес из адресной строки (он начнется с `file:///...`).
3. Зайдите в **Настройки** браузера (Settings).
4. Перейдите в раздел **Запуск / При запуске открывать** (On startup).
5. Выберите пункт **Ранее открытые вкладки** или **Заданные страницы** -> **Добавить новую страницу** и вставьте скопированный путь `file:///...`.
*Примечание: Чтобы страница открывалась и при нажатии на кнопку "Новая вкладка", установите расширение вроде "Custom New Tab URL".*

#### Mozilla Firefox
1. Откройте файл `index.html` в браузере и скопируйте путь `file:///...` из адресной строки.
2. Перейдите в **Настройки** (Settings) -> раздел **Начало** (Home).
3. В выпадающем списке **Домашняя страница и новые окна** (Homepage and new windows) выберите **Кастомные URL** (Custom URLs).
4. Вставьте скопированный путь к файлу.

#### Microsoft Edge
1. Скопируйте путь к файлу `index.html` (`file:///...`).
2. Перейдите в **Настройки** -> **Стартовая страница, главная и новые вкладки**.
3. В блоке **При запуске Edge** выберите **Открыть эти страницы**, нажмите **Добавить страницу** и вставьте путь.

### How to set MikaruStart as your homepage:

#### Google Chrome / Opera / Brave
1. Download the project files and save them to a local folder (e.g., `C:/MikaruStart/`).
2. Open `index.html` in your browser. Copy the full path from the address bar (it starts with `file:///...`).
3. Open browser **Settings** -> **On startup**.
4. Select **Open a specific page or set of pages** -> **Add a new page**.
5. Paste the copied `file:///...` path and click **Add**.
*Note: To open it when clicking "New Tab", use a third-party extension like "Custom New Tab URL".*

#### Mozilla Firefox
1. Open `index.html` and copy the URL starting with `file:///...`.
2. Go to **Settings** -> **Home**.
3. Under **Homepage and new windows**, choose **Custom URLs...**.
4. Paste your `file:///...` path into the field.

#### Microsoft Edge
1. Open `index.html` and copy the `file:///...` path.
2. Go to **Settings** -> **Start, home, and new tabs**.
3. Under **When Edge starts**, select **Open these pages**, click **Add a new page**, and paste the path.
